# tainted-grail-assets

Тайлы подложки и картинки из окон меток для интерактивной карты [Tainted Grail: The Fall of Avalon](https://broskiplay.ru/tainted-grail-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/<карта>/<z>/<строка>/<столбец>.webp` — тайлы четырёх карт (z — уровень Leaflet от −3 до −1)
- `popups/<id>.webp` — картинки из окон меток (id — первые 12 символов UUID оригинала)
